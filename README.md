# Lforlowe.dev\

Personal portfolio of **Louie Jae Maravillosa**, Full-Stack Developer.

Built with Next.js (App Router), React, TypeScript, and Tailwind CSS v4.

## Development

```bash
npm install
npm run dev     # http://localhost:3000
npm run lint
npm run build
```

## Structure

- `app/page.tsx` — single-page layout composing the sections
- `app/components/` — Navbar, Hero, BentoMetrics, Projects, Experience, TechStack, Footer
- `public/` — avatar images used by the hero's pixel/photo spotlight
